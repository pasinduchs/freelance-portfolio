# Pasindu Chameera — Civil Engineering & Revit Portfolio

A six-page, responsive portfolio built with plain HTML, CSS and JavaScript. It uses a midnight navy / champagne palette, a persistent light/dark theme switch, a shared floating navigation pill, and Playfair Display + Manrope typography. It is designed for GitHub Pages and has no build step.

## Preview locally

1. In File Explorer, open this project folder (`outputs`).
2. Double-click `index.html`. It opens the Home page in your browser.
3. Use the header or footer links to open About Me, Projects, Skills & Tools, Services and Contact Me.

The site uses relative paths, so the pages, `styles.css`, `script.js`, `pc-monogram.png`, `Pasindu_Chameera_CV.pdf`, and `assets` folder must stay together in this folder. A simple local web server also works if you use one, but it is not required for the static pages.

## Portfolio content

- Home introduces the Civil Engineering undergraduate and his plan-based Revit modelling work.
- About Me includes the existing portrait and certificate collage.
- Projects identifies practice and planned portfolio examples clearly; it does not claim client work.
- Skills & Tools describes current software use without overstating proficiency.
- Services describes the plan-to-Revit modelling scope and its limits.
- Contact Me contains the provided contact links and Formspree form (`https://formspree.io/f/mjygreng`).
- The CV links to `Pasindu_Chameera_CV.pdf`.

The theme choice is stored in this browser and shared across all six pages on the same site origin. The contact form requires a network connection and a correctly configured Formspree account. A successful live submission has not been verified here. Test with a message you are comfortable sending and confirm receipt in the Formspree account/email.

## Current media limitations

The project contains one portrait and one photograph collage of certificates, rather than separate certificate scans. The portfolio displays the existing files as provided. The Home hero continues to use the existing remote architectural house image reference; it needs internet access to load.

No publish, deploy, or merge action is part of this project update.
